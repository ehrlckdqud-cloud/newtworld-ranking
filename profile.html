내 페이지 인증

본인의 현재 카카오톡 닉네임을 입력하세요. 인증코드는 오픈채팅방에서 직접 말해야 하며, 코드가 확인되어도 관리자 승인 전에는 연결되지 않습니다.

동명이인이 실제로 존재하면 자동 신청을 막고 관리자 확인으로 전환합니다. 닉네임만 같다고 자동 승인되지 않습니다.

내 프로필 정보 수정

보유종은 선택 목록이 아니라 직접 입력합니다. 가장 대중적으로 쓰이는 종명을 적고, 검색 정확도를 위해 가급적 줄임말·개인 별칭 대신 전체 이름을 사용해주세요. 예: ‘화이트트리프록’ 권장 / ‘화트프’ 비권장.

512×512px 또는 1080×1080px를 추천해요. 구슬은 원형이므로 중요한 부분은 중앙에 놓고 모서리에 여백을 주세요.

다른 기기·브라우저 연결

연결 코드는 본인만 사용하고, 톡방이나 다른 사람에게 공유하지 마세요.
