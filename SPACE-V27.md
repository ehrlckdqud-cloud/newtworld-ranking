# Space Escape v27 — lobby coin chime

Increasing the valid expanded participant count through the lobby name input or sample button plays one restored coin chime per input action. Bulk paste and multipliers use one chime for the batch. Initial saved-roster restoration, removal, same-count renaming, winner/duration settings and reset are silent. Invalid input does not update the roster or play a cue. The existing sound toggle and volume apply.

The sound is rendered from the original Metal Slug 3 M1 Z80 driver: system command byte 0x0f dispatches through 0x120e to 0x12ee, loads the fixed SSG sequence descriptor at 0x1693 and jumps to 0x41e0. Recorded YM2610 writes are replayed through YMFM. The active arpeggio spans 0.2568–0.75596 seconds; the packaged 24 kHz mono WAV retains the complete cue and silence margin (trim 0.24–0.88 seconds, duration 0.64 seconds). Asset metadata records the command, execution parameters and SHA-256. Generic Neo Geo documentation's 0x7f coin example is not the command used by this game's driver.

UI playback uses the AudioContext clock, independent of frozen lobby simulation time. The first gesture loads/decodes only the requested coin sound; subsequent calls reuse the buffer. Starting a round, muting or resetting invalidates pending playback, and game/mute state is rechecked after loading. Master output is connected once, avoiding gain stacking on repeated unlock calls. Combat and pickup events keep their existing playback path.
