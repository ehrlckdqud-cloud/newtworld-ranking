# 뉴트젬 운영

기본 보상 1,000젬 + 누적 총점 1점당 1젬을 지급하고 사용분을 차감합니다. 관리자 정정은 별도 가감합니다. 기존 지갑은 종전 earned 원장에서 이미 적립한 증가분을 제외하고 미지급 총점만 1회 보충합니다. 기존 사용분과 수동 정정은 보존합니다. 점수 정정으로 총점이 내려가도 자동 회수하지 않고, 이미 지급한 최고 점수까지는 중복 적립하지 않습니다.

기본 마블 코스는 1회 20젬입니다. 럭키 팩토리·생존연못·우주대탈출은 관리자 전용입니다.

내페이지는 기존 인증된 profileData 응답의 gemBalance를 표시합니다. 별도 iframe POST 없이 회원정보와 함께 조회하며, 오류 시 잔액을 0으로 추정하지 않습니다. 초록색 보석과 `내 뉴트젬 : xxx젬` 한 줄만 표시합니다. 사용 내역은 서버 원장에 보존합니다.
