# 뉴트젬 운영 시작

내페이지에는 초록색 보석과 젬 단위 잔액·내역을 표시합니다. 기본 마블 코스는 1회 20젬, 최초 보상은 1,000젬입니다.

첫 인증된 콘텐츠 API 요청에서 1회 전환합니다. 기존 잔액과 외부 고객 이용권은 보존하며, 아직 지갑이 없는 재실 회원은 현재 누적 점수를 기준으로 초기화합니다. 이후 증가분을 적립하며 과거 점수는 소급 지급하지 않습니다. 전환 완료 후에는 관리자의 운영 중지·요금 변경을 덮어쓰지 않습니다.

럭키 팩토리·생존연못·우주대탈출은 관리자 전용입니다. 외부 고객은 기존 기간·횟수 이용권을 사용합니다. 관리자 실행은 차감하지 않습니다.
