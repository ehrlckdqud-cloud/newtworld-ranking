# 게임 접속 및 코스별 뉴트젬 관리

회원 확인은 기존 회원정보와 같은 JSONP 조회로 처리합니다. 같은 계정·모드의 동시에 발생한 조회는 하나로 합칩니다. 실행·설정 변경은 숨긴 폼 POST를 사용하고 무작위 nonce로 결과만 조회합니다. fetch/CORS 결과에 의존하지 않습니다.

관리자 → 뉴트젬·외부 고객 관리에서 마블 기본 코스 4개, 럭키 팩토리, 생존연못, 우주대탈출의 요금을 각각 설정합니다. 초기 코스 비용은 종전 게임 비용을 계승합니다. 비공개 게임은 요금 설정과 별개로 관리자 전용을 유지합니다. 서버가 코스 ID와 비용을 검증하며 표시한 금액이 달라졌으면 다시 확인합니다.

회원 선택 → 지급/차감 → 양수 수량 → 사유로 잔액을 조정합니다. 최신 총점을 적립한 뒤 요청량을 가감하고 음수 잔액은 허용하지 않습니다. 요청번호를 재사용해 중복 반영을 막습니다.

랭킹은 월간·누적 점수 필터를 지원합니다. 누적 순위는 동점 경쟁 순위이며, 월간 순위 변화 표시는 누적 보기에서 숨깁니다. 회원 상세보기에는 두 순위를 같이 표시합니다.
