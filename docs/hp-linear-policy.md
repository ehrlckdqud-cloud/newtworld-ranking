# 체력 정책 변경 및 예외 조사

사용자 요청: 인원 N의 HP = H1 + (N-1)*(H2-H1). H1=H2이면 3~5인도 동일. 몬스터 및 구조물 대상. 기존 수동 3~5인 입력 계획을 대체한다.

출처: 사용자 첨부 메탈슬러그3_체력입력_초안(2).xlsx. 2026-11-02 읽기 전용 분석. 아직 게임 코드 및 체력값 배포 변경 없음.

## 항목별 조사
고정 ID가 있는 총927행 중 단일 숫자 쌍882행: 증가395, 동일486, 감소1. 여러 값 후보가 있는 동일 목록6행. 2인 미확정39행. 이는 개체 종류 수가 아니라 표/인덱스 및 코드 항목 수다.

감소 항목: 체력 입력!71행, MS3-T444900-I2, 해저 소형 갑각류 적(이동 자세), 미션3/구간1, PC 0xc9e52, H1=30/H2=10. 산술 외삽은 3~5인 -10/-30/-50이므로 그대로 적용 불가. 사용자에게 예외 처리 선택을 질문했으나 먼저 예외 규모/공통점 조사를 요청받았다. 처리 방식은 아직 미결정.

같은 표 0x444900의 인덱스0=30/30, 1=10/10, 2=30/10, 3=60/60, 4=60/60, 5=60/60. 나머지5행에는 감소가 없다. 표의 관찰/미확인 상태를 동일하게 취급하지 않는다. 의도된 원본 예외인지 추출/식별 문제인지는 원본 실행/바이트 추가 대조 없이는 확정하지 않는다.

0/0 항목6행은 감소 예외가 아니라 실행 미확인 정적 후보: T442580 인덱스4/5, T442722 인덱스4/5, T444F80 인덱스4/5. 사용되지 않는 슬롯인지 실제 체력인지 미확정이며 체력0 적으로 단정하지 않는다.

## 적용 전 남은 확인
- 감소1행 원본 재검증 및 3~5인 처리 결정.
- 2인 미확정39행의 실제 값/용도 조사. 32767,28672 등의 값은 특수값 가능성을 검증하고 임의 선형 확대하지 않는다.
- 동일 후보 목록6행은 해당 분기마다 동일값 유지하되 실제 분기 식별.
- HP 전용 초기화 지점에만 적용. 기존 분석상 공용 표 읽기 루틴 0x781e는 타이밍에도 쓰이므로 전역 배율 변경 금지.
- 전체 몬스터/구조물 적용은 실제 HP 저장 경로 검증 후 완료로 표시한다.
