검증: `space-combat-rules.cjs`, `space-score.cjs`, `space-mission.cjs`, `space-live-combat.cjs`, `space-escape-integration.cjs`. 통합 검사는 2/20/50/100/300명 × 90/120/180초 15개 조합, 최종 당첨 인원과 전체 보스 전환·진입 종료를 확인한다. 별도 로컬 QA에서 50명 전투의 종료, 음악 전환 표시, 원본 캡션 표시와 설정창을 확인했다. 실제 사이트 관리자 인증은 유지되며 QA용 진입 코드는 제품 소스에 포함하지 않는다.

복원 근거: `draw/space-assets/mission-provenance.json`, `mission-frames.json`. 원본 캡션 250상태씩을 조사했으며 실제 표시 프레임만 전송한다. 캡처 도구와 렌더링 도구는 별도의 복원 작업본에 보존한다. 운영 사이트에는 검증된 연출 프레임과 게임 실행 파일을 배포한다.

전송 안정성을 위해 두 진행 음악은 작은 조각으로 저장한다. 브라우저에서 순서대로 합친 원본 MPEG 바이트를 재생하며, 음질·길이·음악 자체는 변경하지 않는다. 조각 순서·원본 크기·SHA-256은 `draw/space-score-assets.js`에 기록한다.
