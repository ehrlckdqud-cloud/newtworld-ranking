# 우주탈출 v12

첨부 블랙홀 영상과 원본 메탈슬러그 C(Enemy Chaser) 무기를 게임에 연결했다.

## 블랙홀

- 첨부 MP4의 192개 프레임(24fps, 8초)을 투명 배경 프레임 아틀라스로 변환했다. 오디오 스트림은 포함하지 않는다. 흰 매트 제거와 프레임 가장자리 페더링으로 우주 배경에 합성한다.
- 기존 블랙홀 이벤트 3개 중 1개만 출현한다. 표시 너비는 3배, 체류 시간은 5.2초에서 15.6초다. 영상 재생은 게임 시간에 맞춰 일시정지·배속·재시작을 따른다.
- 화면 밖에서 접근한 뒤 가까운 탐험가 우주선을 중심으로 당긴다. 탈락 가능한 우주선은 선체 모양으로 회전하며 중심에 흡수된다. 기존 당첨 인원·후반 선정 유예·보호막 규칙은 유지하고, 보호된 우주선은 중심 주변 궤도를 돈다.
- 큰 영상 자산은 192KiB 이하 조각으로 전송한다. 매니페스트에 원본 영상 및 변환 결과의 SHA-256, 조각별 크기와 해시를 기록했다.

## 원본 C무기

`draw/space-assets/c-weapon-native.json`에 원본 주소와 프레임·팔레트·사운드 근거를 기록했다.

| 동작 | 원본 근거 |
| --- | --- |
| C 아이템 | 항목 `0x6b16e`, 초기화 `0xc735c`, 표시 스트림 `0x3cc122` |
| 무기 지정 | `0x6bd0e`에서 무기 12 지정, 레코드 `0x21ca6` |
| 획득 이펙트 | `0xc74ec`, 스트림 `0x3cc0a8`, 팔레트 `0x380` |
| 무기명 음성 | 원본 명령 `0x1158` |
| 발사체·추적 | `0xb0e76`, 방향 스트림 `0x3bd62a`, 추적 갱신 `0xb0f38` |
| 발사 이펙트·소리 | `0xeb62e`, `0x3d9fa2`, 명령 `0x10f5` |
| 명중 이펙트·소리 | `0xb1046`, `0x3bdc2e`의 명령 `0x1025`와 콜백 `0xb08ba`, 폭발 스트림 `0x37a8de` |

일반 적·소형 우주선·1차 보스가 실제 체력 소진으로 파괴될 때 확률로 드롭한다. 아이템은 가까운 비장착 우주선으로 이동하고, 접촉한 우주선만 20초간 C를 쓴다. 같은 우주선의 동시 미사일 수는 원본의 3발 제한을 따른다. 추적 방향 스프라이트·발사 이펙트·명중 폭발과 소리는 원본 데이터에서 복원했고, 게임 좌표계의 이동·피해량·20초 지속 시간은 이 게임에 맞춘 동작이다. 여러 척이 동시에 획득할 때 획득 음성을 겹치거나 중간에 끊지 않는다. C가 끝나면 기존 양쪽 H 발사구 공격을 자동으로 재개한다.

## 검증

- `node tests/space-v12.cjs`: 영상 조각/해시/무음 프레임, 출현·크기·체류 비율, 중력 이동·해제, 실제 사망 1회당 드롭, 원본 자산 근거, 획득·음성·추적 명중·동시 3발 제한·20초 복귀.
- 기존 v10/v11·미션·음악·전투·전투 규칙·전체 통합 테스트 통과. 전체 통합은 2/20/50/100/300척과 90/120/180초의 15개 조합에서 최종 인원 선정·보스전·진입 완료를 확인한다.
- 브라우저에서 50척 예시 명단으로 영상 합성·흡입·C 아이템·미사일·폭발·남은 시간을 확인했다. 검증용 제어와 인증 대체 코드는 배포하지 않는다.
