# 우주탈출 v13

1. 거대우주선은 기록된 출구 개방 구간과 무관하게 이동 중에도 소형 우주선을 반복 출격시킨다. 출구에서 나오는 초기 모습은 원본 스프라이트를 사용하고, 분리된 기체는 관성 이동을 이어간다. 기록 경로의 반복·부모 위치 변경으로 되돌아가거나 순간 이동하지 않는다. 최종 모선의 전기 공격 중 출격 제한은 유지한다.
2. 블랙홀은 게임 시간의 22%, 62% 시점에 총 2회 등장한다. 각 15.6초 유지하며 마지막 2.4초 동안 부드럽게 페이드아웃한다. 영상 프레임·무음 상태·3배 크기는 유지한다.
3. 오른쪽에 생존자와 탈락 순서를 별도 스크롤 목록으로 표시한다. 닉네임이 같은 여러 기체도 탑승 번호별로 각각 표시한다. 탈락 번호는 실제 체력이 0이 되는 순간 한 번만 부여한다.
4. 출발 시 무장 없이 시작한다. 각 기체 앞에 H 아이템을 한 개씩 배치하고, 전원이 각자 획득한 후 영구 H 공격을 시작한다. C가 끝나도 획득해 둔 H로 복귀한다. 원본 H 아이템과 공유 무기 획득 이펙트, Heavy Machine Gun 음성을 사용한다. 동시에 획득하는 인원들의 음성을 겹치거나 잘라서 재생하지 않는다.
5. C 드롭 확률을 사망당 16%에서 1.5%로 낮추고, 한 판 전체 생성 수를 최대 9개로 제한한다. 아이템은 무작위 방향으로 계속 부유하고 화면 경계에서 반사되며, 실제 접촉 시 획득한다. 획득·화면 이탈 여부로 전체 생성 한도가 다시 늘어나지 않는다.
6. 버퍼 길이보다 늦어진 효과음을 먼저 채널에 등록해 영구 점유하던 오류를 수정한다. 늦은 짧은 소리는 채널을 차지하지 않고, 정상 재생한 채널은 종료 시 해제한다. 같은 효과음의 과도한 중첩을 제한하고 보스 효과음의 재생을 보장해 총성·적 공격·폭발·획득 음성이 공존하도록 한다.

## H 원본 근거

`draw/space-assets/h-pickup-native.json`에 픽셀·팔레트·프레임과 음성 근거를 기록했다.

- H 아이템 레코드 `0x6b126`, 초기화 `0xc732c`, 표시 스트림 `0x3cc0e6`, 팔레트 `0x37d`.
- 무기 지정 콜백 `0x6bcea`에서 무기 5 지정. 원본 획득 음성 명령 `0x112d`.
- 공통 무기 획득 이펙트 초기화 `0xc74ec`, 스트림 `0x3cc0a8`, 팔레트 `0x380`.
- 원본 M1/V 데이터를 YM2610으로 렌더링한 음성, 원본 애니메이션 인터프리터로 추출한 H 스프라이트를 사용했다.

## 검증

`tests/space-v13.cjs`는 참가자 300척의 개별 H 획득·영구 유지, 2회 블랙홀과 페이드, 사망 1,000회의 C 최대 9개 제한, C 무작위 이동·경계 반사, 늦은 짧은 음원 40개의 채널 누수 방지, 보스·무기 효과음 동시 재생, 자유 출격과 기록 경로 종료 후 연속 이동을 검사한다.

기존 통합 검사는 2/20/50/100/300척 × 90/120/180초의 15개 조합에서 전원 H 획득, 정확한 실제 탈락 순번, 당첨 닉네임 중복 방지, 최종 인원 선정 시점, 보호막과 모선 진입을 함께 확인한다. 브라우저에서 50척의 보급 연출과 분리된 생존·탈락 목록, 거대우주선 이동 중 출격을 확인하고 보스 등장 후 총성·적 공격음 등 여러 원본 음원의 실제 재생 채널을 확인했다.
