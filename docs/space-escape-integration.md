# 우주탈출 연결본

운영 저장소의 기준 커밋은 `8c2dd1fd013b649b4d27c7a23d8b3b2cbc080bca`입니다. 당시 저장소와 원격 브랜치에는 우주탈출 실행 코드가 없었습니다. 앞서 정한 상승·공격·보호막·도킹 규칙을 기준으로 별도 실행본 `draw/space.html`을 추가했습니다. 마블 생존추첨·생존연못은 유지하며, 메인의 게임 선택창에 우주탈출 입구를 추가합니다.

## 연결 범위

- 소형/대형 운석, 적 UFO, 다섯 원형 몬스터, 외계인 탑승형 소형 우주선의 복원 이미지·모션·원본 효과음8개.
- 원형 몬스터의 각 체력·충돌·파괴 상태는 독립적이며 연쇄 사망을 사용하지 않습니다.
- 참가자1~300명. 참가자 우주선은 자동 이동·사격하며 실제 탄환/개체/레이저/블랙홀 충돌로 탈락합니다. 당첨 인원 아래로 탈락시키지 않습니다.
- 출발6.2초까지 가속·사격 대기. 목표 생존 인원 도달 시 모든 공격을 중지하고 보호막→도킹→당첨 명단 표시로 전환합니다.
- 효과음의 명령별 원본 지연/길이를 연결합니다. 정지·속도 변경·음소거·초기화 시 기존 음원 노드를 중단합니다.
- 기존 `drawMemberAccess` 및 `drawAvatarIndex`/`drawAvatarImages`를 사용합니다. 로그인 상태가 변경되면 게임을 정지하고 다시 확인합니다. 회원/결과/사진을 쓰는 서버 호출은 추가하지 않았습니다.
- 로컬 조종석 사진은 페이지 메모리에만 보관하고, 명단과 당첨 인원 설정만 브라우저 저장소에 저장합니다.

## 복원 자산과 게임 규칙의 구분

원본 ROM에서 확인한 그림·프레임·효과음을 사용하지만, 참가자 우주선·우호/적 모선·블랙홀·레이저의 도형과 게임의 체력·이동·출현 간격은 이 우주탈출 실행본의 규칙입니다. 전체 메탈슬러그 원본 AI나 미션을 재현했다는 뜻이 아닙니다. H 무기 드롭은 제외합니다.

`tools/build-space-assets.py <선택 자산 묶음 디렉터리>`로 재생 자산을 만들었습니다. 411개 원본 부품 이미지를 2048×506 단일 아틀라스로 합치면서 전부 픽셀 일치를 확인했습니다. 원본 묶음 식별자는 `draw/space-assets/provenance.json`에 기록되어 있습니다. 실행에는 Python이나 ROM이 필요하지 않습니다.

## 검증

`node tests/space-escape-integration.cjs`

- 1·2·12·50·300명, 복수 당첨 인원과6개 난수 시드로30판을 완료했습니다. 최대82초의 시뮬레이션에서 정확한 당첨 인원·중복 없는 탈락/생존 분리를 확인했습니다.
- 시작 사격 지연, 투사체의 연속 충돌, 넓은 레이저의 동시 충돌에서도 당첨 인원 초과 탈락 방지, 도킹 중 사격 중지, 다섯 몬스터 독립 파괴를 확인했습니다.
- 인증 캐시·로그아웃·인증 요청 중 계정 변경·중복 이름 사진 매칭 거부를 검증했습니다.
- 기존 사이트 검사8개가 통과했습니다. `badge-details-v336.cjs`는 변경 전 기준에서도 `document.createElement`가 없는 기존 VM 스텁 때문에 동일하게 실패합니다. 배지 코드는 수정하지 않았습니다.

Chrome 내부 검증: 실제 비인증 접근 차단을 확인했습니다. 서버와 실제 회원 기록을 건드리지 않는 별도 인증 응답으로12명/당첨3명 전체 비행→탈락9명→보호막→도킹→당첨3명 표시를 확인했습니다. 이 검증 전용 인증 파일과 HTML은 배포 소스에 포함하지 않습니다. 실제 운영 로그인 세션·회원 사진 서버와의 최종 확인, 실제 모바일 기기 검증은 배포 후 확인 대상입니다.

## 반영

기존 개발 규칙에 따라 PR 결과 확인 후 사용자 승인으로 병합·배포합니다. 백엔드 변경은 필요하지 않습니다. 배포 후 기존 회원 세션으로 `draw/space.html` 및 메인 게임 선택창을 확인합니다. 문제가 있으면 이 프런트 PR을 되돌리면 기존 게임과 회원 데이터는 유지됩니다.


## 관리자 전용 업로드 (2026-10-22)

사용자 승인에 따라 복원 이미지·효과음을 기존 공개 저장소에 업로드하고 운영 사이트에서 관리자 테스트용으로 제공합니다. 며칠 전 우주탈출 원본과 다른 신규 실행본임을 사용자에게 알렸습니다.

- 일반 게임 선택 화면에서는 우주탈출 카드를 제거하고 기존 관리자 허브에만 테스트 링크를 둡니다.
- 회원식별 확인과 기존 관리자 비밀번호 인증(`adminLogin`, SHA-256) 및 서버 관리자 토큰 확인(`adminPartnerData`)을 모두 통과해야 자산을 불러오고 실행합니다.
- 관리자 토큰은 이 페이지 메모리에만 보관하며, 시작 시·재진입 시·30초마다 재검증합니다. 실패/만료/회원 로그아웃 시 즉시 게임을 잠그고 정지합니다.
- GitHub Pages는 정적 호스팅이므로 공개 저장소의 소스와 개별 자산 URL 자체를 비공개로 만드는 것은 아닙니다. 관리자 제한은 기존 생존연못과 동일한 실행 진입 제한입니다.
- 관리자 인증의 잘못된 비밀번호·토큰 취소·만료·검증 도중 로그아웃을 자동 검증합니다. 실제 관리자 비밀번호를 입력하는 운영 인증은 사용자 확인이 필요합니다.
