# 우주탈출 — 공유 원본 기반 복원 자산 연결

## 기준과 교체 범위

사용자가 제공한 공유 페이지에 포함된 `newtworld-space-effects.html` 원본(NEWTWORLD · 3단계 효과 · 사운드)을 기준으로 합니다. 추출 HTML의 SHA-256은 `a51a0ca197e91d7d345a3405c13dae40f72c5f2a916d031a35d3ce8b76162d3a`입니다.

PR #13의 별도 구현인 `space-app.js`, `space-core.js`는 제거했습니다. 원본의 CSS/배경·참가자 우주선·적 전함 이미지·수직 상승·추진기·피격·폭발·보호막·모선 도킹·조종석 사진 UI를 유지합니다. 원본 장면 이미지 바이트는 WebP 그대로 `space-assets/original-scene.webp`로 추출했습니다. 공유 페이지의 호스트 전용 테마/선택/캐러셀 보조 스크립트는 가져오지 않습니다.

- 탑승자 2~300척, 당첨 인원, 비행 시간 45/60/90/120초, 실시간/3배속 선택을 유지합니다.
- 원본의 암호학적 셔플 및 사전 피해 일정으로 당첨자를 결정합니다. 몬스터 처치가 당첨 확률을 바꾸지 않습니다.
- 6.2초 가속 후 사격하며, 당첨 확정 즉시 모든 사격을 중지합니다. 남은 생존자는 보호막을 받고 원본 모선에 도킹합니다.

## 복원 자산 연결

`space-encounters.js`에서 소형/대형 운석, UFO, 원형 몬스터 5마리 편대, 외계인 탑승 소형 우주선을 원본 등장 일정에 연결합니다. 블랙홀과 측면 레이저는 원본 장면에 남깁니다.

- 각 원형 몬스터는 독립 ID·체력·탄환 충돌·피격·사망 상태를 갖습니다. 한 마리의 처치가 나머지를 죽이지 않습니다.
- 실제 선분 충돌을 통과한 참가자 탄환이 각 몬스터 체력을 깎고 피격/파괴 클립을 실행합니다. 복원한 외계인 발사 지연(10프레임)을 적용합니다.
- 원본 자산 18클립·효과음 9개를 재사용합니다. 대형 운석의 파괴·분리음, UFO·생체 몬스터·외계인 기체별 효과음을 해당 원본 클립에 연결합니다. H 무기 드롭은 제외합니다.
- 일시정지·음소거·음량 변경·3배속·재추첨 시 복원 사운드도 함께 제어합니다. 기존 시안의 합성 엔진/참가자 피격/전함 효과음은 유지합니다.
- 원본의 피해 일정과 호스트 이동 규칙을 사용하며 메탈슬러그 전체 AI를 재현한 것은 아닙니다.

## 관리자 전용 공개

생존연못과 동일하게 메인 생존추첨 선택창에 `우주탈출(개발중)` 카드를 표시합니다. 카드 설명과 버튼에 관리자 전용을 표시하며 숨기지 않습니다.

기존 회원식별(`drawMemberAccess`)과 관리자 비밀번호(`adminLogin`, SHA-256), 서버 관리자 토큰 확인(`adminPartnerData`)을 모두 통과해야 게임 모듈·장면 이미지를 불러오고 실행합니다. 시작/페이지 복귀/30초 주기 재검증, 권한 만료/로그아웃 시 즉시 잠금 및 정지합니다. 관리자 토큰은 페이지 메모리에만 보관합니다. 새로운 서버 쓰기 동작을 추가하지 않습니다.

GitHub Pages의 공개 소스·개별 자산 URL 자체가 비공개로 바뀌는 것은 아닙니다. 기존 생존연못과 동일한 게임 실행 진입 제한입니다.

## 검증

`node tests/space-escape-integration.cjs`: 원본 코드 기반으로 2/20/100/300척 × 45/60/90/120초 총 16개 전체 게임을 실행해 원본 셔플 결과·정확한 생존 인원·도킹 종료·도킹 중 사격 중단을 확인합니다. 다섯 원형 개별 처치, 외계인 10프레임 지연, 탄환 선분 충돌, 관리자 권한 취소/만료, 일반 선택창의 공개 카드 및 이전 실행 코드 제거를 확인합니다.

브라우저 QA: 원본 화면에서 20→3명 생존 및 모선 도킹, 효과음 활성화, 복원 몬스터 전투를 점검합니다. QA 인증 fixture는 검증 디렉터리에만 있으며 저장소와 배포에서 제외합니다. 실제 관리자 비밀번호 입력 및 실물 모바일 기기 확인은 사용자 확인 범위입니다.

기존 회귀 테스트의 `badge-details-v336.cjs`는 수정 전 기준에서도 document.createElement 스텁 부재로 실패하며 관련 코드는 변경하지 않습니다.
