# 포인트 관리 페이지 로그인 복구

2026-11-02

## 문제

포인트 관리 페이지는 contentAdminList 인증 실패를 안내문으로만 표시했다.
관리자 허브는 sessionStorage의 토큰 존재 여부로 진입하므로, 만료된 토큰이 남아 있거나 페이지를 직접 열면 비밀번호 입력 경로가 없었다.

## 변경

- 토큰이 없으면 페이지에서 기존 관리자 비밀번호 대화상자를 표시한다.
- 기존 토큰은 실제 목록 API로 검증한다. 서버의 관리자 인증 실패 응답일 때만 제거하고 재인증한다.
- 기존 adminLogin 엔드포인트와 SHA-256 인증 방식을 사용하고, 발급 토큰은 기존 sessionStorage 키에 저장한다.
- 인증 후 목록 API를 다시 호출하여 확인된 관리자에게만 본문을 표시한다.
- 취소, 비밀번호 오류, 연결 실패에는 재시도 버튼을 제공한다. 일반 서버 오류를 토큰 만료로 취급하지 않는다.
- 자동으로 젬 지급/회수 요청을 재실행하지 않는다. 기존 서버 권한 검사와 메인 관리자 진입 제한은 유지한다.
- HTML의 관리 스크립트 버전을 갱신한다.

## 검증

- node tests/admin-access.cjs: 토큰 없음/정상/만료, 취소, 비밀번호 오류 및 재시도, 네트워크 오류, 일반 서버 오류, SHA-256 전송, 콜백 정리.
- node tests/admin-usage.cjs: 뉴트젬 현재/사용/TOTAL, 검색, 회원 선택 유지.
- 변경 JavaScript 구문 검사.

실제 관리자 비밀번호를 입력하는 운영 계정 로그인은 자동 검증하지 않았다.
