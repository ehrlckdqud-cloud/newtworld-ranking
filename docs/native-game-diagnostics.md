# 미션 3 엘리베이터 조사 / v88 진단 보강

2026-11-02 한국 시간

사용자는 이전 엘리베이터들도 바닥까지 내려오지 않는다고 추가 신고했다.
따라서 한 번의 플레이어 충돌 상태 잔류로 원인을 단정하지 않는다.

두 번째 v87 진단은 600개 샘플/500개 이벤트이며, 마지막 30초는 초당 58~60프레임이다.
이벤트에는 순간 입력 대기 및 HTTP 오류도 있으나 미션·객체 상태가 없어 엘리베이터 문제와 연결할 수 없다.
현재 원인 미확정, 엘리베이터 동작 수정 전이다.

## 이번 변경

- 게임 오류·끊김 기록 JSON 저장 버튼에서 v88 JSON을 내보낸다.
- 2초 간격, 최대 30회(약 1분)의 미션·구역·진행 루틴·활성 마스크·참가 인원·플레이어 위치/부모 객체·활성 객체 상태를 추가한다.
- 내보내는 순간에는 현재 상태를 추가로 캡처한다.
- 객체 로컬 좌표와 화면 좌표를 분리한다. 상대 좌표를 월드 좌표로 오인하지 않는다.
- 숫자 필드 이름 words0c/words44는 구조체의 시작 오프셋이다. 특정 플래그의 의미를 확인하기 전 충돌 플래그로 단정하지 않는다.
- 네이티브 RAM을 읽기만 하며 프레임/게임 상태/체력/진행 조건을 변경하지 않는다.
- 새 엔진이나 이전 프레임으로 복원 시 기록을 초기화한다. 캡처 실패는 게임 진행에 영향을 주지 않는다.
- 객체 기록은 메모리에만 보관하고 사용자가 JSON 저장을 누를 때만 내보낸다. 기존 주기적 localStorage 저장에 추가하지 않는다.
- 회원명, 채팅, 로그인 토큰, 결제 정보, ROM을 기록에 추가하지 않는다.

## 검증

node tests/game-diagnostics.cjs 통과: 좌표/부모 포인터, RAM 무변경, 기록 주기/최대량, 즉시 캡처, 복사본 격리, 초기화, 오류 처리, 기존 진단의 민감 필드 제외.
변경 JavaScript 구문 검사 통과.

실제 문제 구간에서의 재현 검증과 엘리베이터 수정은 아직 완료되지 않았다.
새 게임에서 증상이 발생하면 게임을 나가기 전에 저장한 v88 JSON으로 객체 루틴과 정지 직전/직후 상태를 조사한다.
