# 우주탈출 v14

C 아이템의 부유 속도를 기존 60–105px/s에서 175–260px/s로 높이고 0.55–1.3초마다 무작위 방향을 선택한다. 각 미장착 생존 우주선이 가까운 아이템의 진행 방향을 예측해 추적한다. 여러 기체가 한 아이템을 경쟁하며 실제 접촉한 한 기체만 획득한다. 획득 후 추적 가속도는 부드럽게 해제한다. 20초 C 지속, 영구 H 복귀, 한 판 최대 9개 규칙을 유지한다.

최종 모선 전기는 원본 전기 프레임을 유지하며 발사 구간마다 좌측·중앙·우측으로 방향을 변경한다. 원본 발사구 (160,65)를 기준으로 그림을 회전하고, 충돌 검사는 같은 회전의 역변환 후 원본 불투명 픽셀로 수행한다. 가까운 기체는 0.38초 앞의 전기 구간도 감지해 위험 통로에서 벗어나도록 조향한다. 회피 시도는 무적을 부여하지 않으며 기존 당첨 보호막과 최종 선정 규칙을 유지한다.

## 첨부 mission5-5.mp4의 구조물과 외눈 적

ROM 원본 M68000 개체·자식 목록을 실행하고 C ROM 그림과 실제 변환 팔레트, 원본 상대 위치·지연값을 추출했다. 영상의 외형과 추출 접촉 시트를 대조했다. `shaft-enemies-native.json`은 추출 기록 해시·원본 주소·팔레트·프레임을 포함한다. 원본 AI의 전체 미션 재현과 구분하여 출현 일정, 게임 화면에 맞춘 이동 속도, 생존 우주선 조향과 체력 배율은 호스트 게임이 처리한다.

| 항목 | 구조물 | 외눈 적 |
| --- | --- | --- |
| 원본 출현 레코드 | 0x41785e | 0x41806c |
| 초기화 | 0xf48dc | 0xc28e0 |
| 몸체 스트림 | 0x3dad90 | 0x3c9ebe |
| 피격 팔레트 | 0x5ac → 0x5ad | 0x949 → 0x920 |
| 공격/손상 부품 | 손상 연기·자식 10개 연쇄 파괴 | 발사광 0x3ca50a, 탄체 0x3ca5ba |
| 폭발 사운드 | 0x11a7, 자식별 4틱 간격 | 0x1022 |
| 출현 | 1게임 5개 | 일반 출현 이벤트 6종 중 1종, 묶음당 2개 |

구조물은 원본 움직임의 위치 추이를 따라 화면을 통과하고, 가로 전체에 실제 사격 판정을 가진다. 체력이 줄면 원본 연기를 표시하며 파괴 시 중앙에서 양쪽으로 원본 분절 폭발이 이어진다. 외눈 적은 원본 몸체 위치 추이와 발사광·자식 탄체 프레임을 사용하며, 실시간 생존자 방향으로 발사한다. 별도 발사 사운드 명령은 원본 해당 개체·애니메이션 기록에 없다. 발사 시 기존에 복원된 원본 공통 발사음 0x11d4, 피격 시 공통 0x1021을 재사용하며 이를 전용 사운드 복원으로 표시하지 않는다.

0x11a7은 원본 M1 실행과 V ROM을 YM2610으로 렌더링했다. 실제 M68000 FIFO 0x11,0xa7 전송 기록을 보존했다. 음악·원본 동영상은 추가 업로드하지 않는다.
