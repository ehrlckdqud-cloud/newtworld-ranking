# 뉴트젬 공통 UI 및 공용 게임 설정 준비

뉴트젬 아이콘은 assets/newt-gem.svg를 내페이지·게임 시작 비용·녹색 확인창에서 공유합니다. 콘텐츠 시작 확인은 NWUI.confirm으로 통일하고, 확인 취소 시 시작 요청과 차감은 발생하지 않습니다. 게임의 비용 표시는 서버 설정을 사용하며 관리자 면제·외부 이용권을 구분합니다.

메인 관리자 로그인은 NWUI.password의 password 입력을 사용합니다. 입력값은 인증 직전 해시하며 대화상자를 닫을 때 지웁니다.

내페이지 누적 순위는 재실 일반 회원의 양수 누적 점수에 경쟁 순위(동점 1,1,3)를 적용합니다. 월간 순위는 기존 순위를 유지하고 방장·부방장의 순위 제외 정책을 유지합니다.

공통 음악·배경·스티커는 `assets/game-defaults/manifest.json`과 `media/`로 배포합니다. 회원이 처음 게임을 열면 비어 있는 보관함에만 공통 설정을 넣습니다. 기존 개인 설정과 의도적으로 비운 재생목록은 덮어쓰지 않습니다. 원본 내보내기의 음악 켜짐/꺼짐·음량도 보존합니다. 음악은 선택된 곡만 HTTP로 읽어 초기 전곡 다운로드를 피하며 배경과 스티커는 SHA-256 검증 후 Blob으로 저장합니다.

관리자 메뉴의 게임 기본설정 내보내기는 해당 3개 보관함의 설정과 Blob 원본, 우주 음악 환경값을 JSON 또는 gzip JSON으로 저장합니다. 공통 음악도 내보낼 때 원본 Blob으로 변환합니다. 인증 토큰·회원 명단·추첨 이력은 내보내지 않습니다. 새 원본은 `python3 tools/import-game-defaults.py /path/to/export.json`으로 추출할 수 있습니다. gzip이면 먼저 압축을 해제합니다. 추출 후 브라우저 검증과 배포가 필요합니다.

현재 공통 설정은 음악 19개, 사진 2개, 스티커 자산 2개, 맵별 배치 11개입니다. 같은 내용의 음악 두 쌍은 해시로 중복 저장을 줄였으며 재생목록 ID는 그대로 유지합니다.
