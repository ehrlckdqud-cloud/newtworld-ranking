# 뉴트젬 공통 UI 및 공용 게임 설정 준비

뉴트젬 아이콘은 assets/newt-gem.svg를 내페이지·게임 시작 비용·녹색 확인창에서 공유합니다. 콘텐츠 시작 확인은 NWUI.confirm으로 통일하고, 확인 취소 시 시작 요청과 차감은 발생하지 않습니다. 게임의 비용 표시는 서버 설정을 사용하며 관리자 면제·외부 이용권을 구분합니다.

메인 관리자 로그인은 NWUI.password의 password 입력을 사용합니다. 입력값은 인증 직전 해시하며 대화상자를 닫을 때 지웁니다.

내페이지 누적 순위는 재실 일반 회원의 양수 누적 점수에 경쟁 순위(동점 1,1,3)를 적용합니다. 월간 순위는 기존 순위를 유지하고 방장·부방장의 순위 제외 정책을 유지합니다.

음악·배경·스티커는 현재 사용자 브라우저 IndexedDB에만 존재합니다. 관리자 메뉴의 게임 기본설정 내보내기는 해당 3개 보관함의 설정과 Blob 원본, 우주 음악 환경값을 JSON 또는 gzip JSON으로 저장합니다. 인증 토큰·회원 명단·추첨 이력은 내보내지 않습니다. 이 파일을 받아 공용 자산과 기본설정으로 배포해야 다른 회원에게 보입니다. 내보내기만으로 공용 적용이 완료되는 것은 아닙니다.
