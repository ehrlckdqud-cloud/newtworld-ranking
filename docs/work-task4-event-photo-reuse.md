## 구현

월간 이벤트 사진 관리에서 이전 월을 고르고 사진을 불러온 뒤, 일부 또는 추가 가능한 사진 전체를 선택해 현재 선택한 이벤트 월로 가져온다. 원본 월과 원본 파일은 유지하며 대상 목록에만 추가한다.

이미 등록된 사진은 선택 불가, 월별 20장 초과는 저장 전 차단, 이전 월만 허용한다. 저장되지 않은 현재 목록 순서·삭제는 먼저 저장한다는 안내를 표시하며 저장 성공 후 새 revision으로 reuse를 요청한다. 대상 저장 충돌이나 원본 revision 충돌 시 성공으로 표시하지 않는다. 성공 후 관리자 목록, 현재 월 표시와 로컬 목록 캐시를 갱신한다.

변경 범위: assets/eventbook/eventbook.js, index.html의 해당 스크립트 캐시 버전, tests/event-photo-reuse.cjs 및 본 문서. Sites/게임 코드와 공통 미디어는 변경하지 않는다.
