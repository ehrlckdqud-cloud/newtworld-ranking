# 게임 관리자모드

기본 마블 코스는 방장·부방장·일반 회원 모두 1회 20젬을 차감합니다. 사이트 메인 관리자 로그인은 차감 면제와 무관합니다.

게임 상단 관리자모드 버튼은 인증된 NW0001 계정에만 표시합니다. 서버도 해당 회원의 기기 인증과 관리자 비밀번호를 모두 확인해 별도 2시간 권한을 발급합니다. 권한은 페이지 메모리에만 보관하며 모드를 끄면 서버에서 폐기합니다. 페이지를 새로 열면 일반 모드입니다. 일반 모드·관리자모드의 실행 요청번호 공간을 분리합니다.

럭키 팩토리·생존연못·우주대탈출의 기존 비밀번호 진입은 유지하며 서버에서도 NW0001 계정을 요구합니다. 기본 코스는 기존 관리자 토큰만으로 면제되지 않습니다.

콘텐츠 요청은 POST로 보내고 결과를 120초 유효한 무작위 nonce 영수증으로 조회합니다. 회원·관리자 토큰이나 비밀번호를 결과 조회 URL에 포함하지 않습니다. 시작 재시도는 기존 요청번호를 유지해 이중 차감을 방지합니다.
