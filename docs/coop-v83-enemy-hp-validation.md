# 메탈슬러그3 v83 적 체력 실측 — 2026-10-30

## 결론

현재 구현은 1~5인 수에 비례하는 체력 배율을 적용하지 않는다. 원본의 체력 표 선택 함수가 유지되어 있으며, 이 함수는 **원본 P1과 P2 개체가 모두 활성 상태인지**로 1인/2인용 열을 선택한다. P3~P5는 이 함수의 인원 검사 대상이 아니다. 이 구분은 방의 접속 인원이나 `activeMask`의 비트 개수와도 다르다.

현재 기본 설정(원본 난이도 바이트 `0x10FD8B = 3`, 게임 모드 `0x10001A = 2`, 측정 개체 subtype 0)에서 얻은 값:

| 초기 참여 좌석 | 미션 1 초반 게 개체 | 미션 4 보스 | 미션 5 최종 구간 보스 |
| --- | ---: | ---: | ---: |
| P1 | 30 | 5,000 | 8,000 |
| P1·P2 | 50 | 7,000 | 12,000 |
| P1·P2·P3 | 50 | 7,000 | 12,000 |
| P1·P2·P3·P4 | 50 | 7,000 | 12,000 |
| P1·P2·P3·P4·P5 | 50 | 7,000 | 12,000 |

따라서 대표 개체의 1인 대비 증가는 각각 약 1.67배, 1.4배, 1.5배다. 모든 적에 공통인 배율이 아니다. HP는 원본 내부 정수 값이며 명중 횟수와 동일하지 않다.

## 좌석 조합과 중간 합류/퇴장

미션 4 보스를 같은 원본 진입 절차로 생성해 비교했다.

| 보스 생성 전 참여 좌석 | 실제 체력 | 원본 선택 결과 D7 |
| --- | ---: | ---: |
| P1만 | 5,000 | 0 |
| P2만 | 5,000 | 0 |
| P1·P2 | 7,000 | 1 |
| P1·P3 | 5,000 | 0 |
| P3·P4·P5 | 5,000 | 0 |
| P1·P3·P4·P5 | 5,000 | 0 |
| P1·P2·P3·P4·P5 | 7,000 | 1 |

- P1만 있을 때 5,000으로 생성된 보스: P2, P3, P4, P5가 차례로 합류해도 기존 체력은 계속 5,000. P2 합류 후 선택 함수는 1을 반환하지만 이미 생성된 보스의 체력을 다시 쓰지 않는다.
- 5인 상태에서 7,000으로 생성된 보스: P5, P2, P1 순으로 퇴장해도 기존 체력은 계속 7,000. P2 퇴장 후 선택 함수는 0을 반환한다.
- 생성 시점이 다른 보스 비교와 이미 생성된 보스의 변경 여부를 별도 검사했다. 모든 적의 재생·변신·부위 교체 시점까지 검증한 것은 아니다.

## 원본 코드와 현재 패치 대조

실행에 실제 사용되는 패치된 P1 ROM과 사용자가 제공한 원본의 다음 구간이 바이트 단위로 동일함을 검사했다. 보고서에는 코드 대신 범위와 SHA-256만 기록한다.

- `0x5804..0x5813`: 해당 개체의 실행 루틴이 `0x567A`인지 검사. 체력 값이나 방 인원 수를 세는 함수가 아니다.
- `0x77FC..0x781D`: 원본 P1 `0x1004FC`, P2 `0x1005AC`를 위 함수로 검사하고 둘 다 활성일 때 D7=1, 그 외 D7=0을 반환.
- `0x781E..0x7919`: 위 결과, 난이도, 개체 subtype으로 원본 데이터 표를 조회. 이 공용 함수는 HP 외의 설정에도 사용되므로 여기에 무조건 인원 배수를 곱하면 안 된다.

각 개체의 HP는 `actor + 0x4E`에서 읽었다. 미션 4 보스는 `0x739C8`, 최종 구간 보스는 `0x9F460`에서 원본 표 조회 결과를 이 필드에 저장한다. 각각의 표 `0x44D000`, `0x44DA00`에서도 현재 조건의 5,000/7,000, 8,000/12,000이 일치한다.

## 실행 조건과 검증 범위

- 현재 프런트엔드 기준 커밋: `fb5710b982aaa47130bc582dba7438c8f9496224` (v83).
- 코어 제공 서버 소스 커밋: `9c61ff7508d80de22c5b58531bc704d276099ced`.
- 실제 WASM 코어와 현재 `coop/native/profile.json`, `FiveSession`을 사용했다. 정확한 파일 해시는 JSON에 기록했다.
- 정상 부팅 체크포인트를 복원해 각 인원 조건을 비교했다. 미션 1 개체는 이동 입력으로 등장시켰다. 보스는 검증 시간을 줄이기 위해 원본의 미션/서브스테이지 진입 루틴으로 이동했다. 미션 4는 `(3,16)`, 최종 구간은 `(4,14)`이며 0부터 시작하는 인덱스다.
- 적 HP, 피해량, 난이도는 변경하지 않았다. 원본 선택 함수 D7 측정만 테스트용 예약 RAM 코드로 수행했다. SR과 D0-D7/A0-A6를 보존하고 기존 개체 루틴으로 복귀하며, 독립 사례마다 전체 상태를 복원했다. 이 관찰 코드는 운영 게임에 포함하지 않는다.
- **51개 검사 통과:** 원본 코드 일치 3개, 인원별 부팅/체력 20개, 좌석 조합 14개, 중간 합류/퇴장 14개.
- 전 미션 자연 진행, 모든 일반 적·보스 부위·변신 단계, 모든 난이도의 체력 목록을 완성한 검증은 아니다. 위 표는 직접 확인한 개체와 조건에 한정된다. 확정되지 않은 적의 수치를 추정하여 채우지 않았다.
- 이번 작업은 현행 동작 검증이다. 체력 밸런스, 결제, 게임 버전은 변경하지 않았다.
